# Autodoc — лента новостей

Тестовое задание Автодок: iOS-приложение с лентой новостей из API `https://webapi.autodoc.ru/api/news/{page}/{size}`.

## Что реализовано

- Лента новостей с постраничной загрузкой: следующая страница подгружается заранее, при ошибке внизу появляется кнопка «Повторить».
- Ячейка: картинка и заголовок. Если картинки нет или она не загрузилась, показывается стандартная заглушка.
- По нажатию открывается новость целиком: картинка, категория, дата, заголовок, описание.
- Кнопка «Читать на сайте» открывает статью в `SFSafariViewController`, «Поделиться» — системный шаринг.
- Состояния экрана: скелетон при загрузке, pull-to-refresh, пустой экран, ошибка с повтором, тост при ошибке обновления.
- iPad: адаптивная сетка (число колонок зависит от ширины), split view «лента + статья», поддержка всех ориентаций, Split View и Slide Over.
- Dynamic Type, тёмная тема, VoiceOver, учёт настройки «Уменьшение движения».

## Технологии

- UIKit, вся вёрстка в коде, без storyboard
- MVVM + Combine
- `UICollectionView` + `UICollectionViewCompositionalLayout` + `UICollectionViewDiffableDataSource`
- Все запросы — async/await
- Swift 6, строгая проверка concurrency (MainActor по умолчанию)
- Без сторонних библиотек: загрузка и кэширование картинок реализованы самостоятельно (actor, `NSCache` + `URLCache`, уменьшение через ImageIO)

## Архитектура

```
App/            запуск, зависимости, координатор, навигация (iPhone / iPad)
Core/           сеть, загрузка картинок, дизайн-токены, расширения
Features/News/
  Domain/       модели NewsItem, NewsPage и протокол NewsRepository
  Data/         DTO, эндпоинт, RemoteNewsRepository
  Feed/         лента: ViewModel, контроллер, layout, ячейки
  Detail/       экран новости
```

- **ViewModel** хранит одно состояние `State`, а View только отрисовывает его.
- **Репозиторий** скрыт за протоколом, поэтому ViewModel не зависит от сети.
- **Навигацией** управляет координатор: на iPhone — `UINavigationController`, на iPad — `UISplitViewController`.

## Запуск

Требования: Xcode 26, iOS 17.0+.

1. Откройте `Autodoc.xcodeproj`.
2. Выберите схему `Autodoc` и симулятор iPhone или iPad.
3. Нажмите Run (⌘R).

Зависимостей нет, ничего дополнительно устанавливать не нужно.
